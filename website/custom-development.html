Principles

Lightest stack that works

Static hosting before servers. Google Workspace tools before custom databases. Shopify before a custom store. Servers only when the brief requires them.

Written scope with exclusions

The proposal names what is not included, so change requests are priced rather than argued.

Verification at each stage

Each build step has a check before the next starts. You see working software early.

Handover you can maintain

Accounts in your name. Documentation for the changes you will make yourself. No dependency on us for routine edits.
